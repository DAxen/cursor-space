1.1 案例一：Claude Code（Anthropic）—— Agentic Search + 分层 Markdown

结论：头部 Agent 的检索主干是"不建索引、现场检索"；跨会话知识用手写分层 Markdown（CLAUDE.md）承载——知识库做成文件，与 Agent 零摩擦对接。
知识管理方式
  • 分层 CLAUDE.md：根文件管全局（<150 行，命令优先），各模块子目录放局部约定，自动加载"离被编辑文件最近的一份"（OpenAI 主仓有 88 个 AGENTS.md）
  • Agentic Search：Agent 反复调用 grep / glob / read 自主缩小范围，不预建任何索引
  • 记忆即文件：跨会话记忆 = 手写 Markdown，拒绝向量召回
为何放弃向量 RAG（作者 Boris Cherny 自述）
  • 精确：grep 精确匹配，embedding 引入模糊误报
  • 简单：无索引可建、可维护、可过期
  • 新鲜：直查文件系统，索引不会"说谎"
  • 隐私：代码不出本机做 embedding
启示
知识库做成结构化 Markdown 文件就是对 Claude Code 最原生的接入方式；大仓库补充 LSP 符号级导航（官方列为最高价值投资）。
